# AI Академія - Telegram Mini App

Це демо-версія мініапки для навчання. Вона містить сторінку профілю, віджет прогресу, активний урок та список модулів.

## Як запустити на GitHub Pages:
1. Створіть новий публічний репозиторій на GitHub.
2. Завантажте всі 4 файли (`index.html`, `style.css`, `app.js`, `README.md`) та вашу картинку з назвою `preview.jpg`.
3. Перейдіть у **Settings** -> **Pages**.
4. У розділі "Build and deployment":
   - Source: `Deploy from a branch`
   - Branch: `main` (папка `/ (root)`)
5. Натисніть **Save** і зачекайте 1-2 хвилини.
6. Отримайте посилання вгорі сторінки (наприклад: `https://ваш_нік.github.io/репозиторій/`).

## Як підключити до бота:
1. Зайдіть у `@BotFather`.
2. Виберіть бота -> `Bot Settings` -> `Menu Button`.
3. Введіть назву кнопки (наприклад, "Навчання") і вставте посилання з GitHub Pages.
